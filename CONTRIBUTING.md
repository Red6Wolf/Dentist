# Правила проекта

Этот файл фиксирует договорённости для всех следующих изменений сайта
семейной стоматологии «Апельсин».

## Читабельный код

- В существующей HTML-разметке сохраняем отступ в 2 пробела; в CSS и JavaScript используем 4 пробела.
- Не минифицируем исходники и не сливаем несколько логических операций в одну строку.
- Один смысловой блок — одна визуально отделённая секция кода.
- Длинные HTML-теги разбиваем на несколько строк, по одному атрибуту на строку.
- В CSS группируем правила по компонентам и оставляем понятные комментарии для крупных секций.
- В JavaScript даём функциям и переменным описательные имена; одна операция — одна строка.
- Пользовательский текст и комментарии пишем по-русски, технические имена классов и файлов оставляем на английском.

## Куда добавлять файлы

- `index.html` — только главная страница.
- `pages/` — внутренние страницы сайта.
- `styles/` — общие и страничные CSS-файлы.
- `scripts/` — JavaScript без inline-скриптов в HTML.
- `assets/clinic/` — фотографии клиники, интерьера и сюжетные изображения.
- `assets/doctors/` — портреты и изображения врачей.
- Корень проекта оставляем для документации и конфигурации: `README.md`, `PRODUCT.md`, `DESIGN.md`, `CONTRIBUTING.md`, `package.json`.
- Новую папку создаём только для отдельной устойчивой категории файлов и сразу добавляем её в структуру `README.md`.

## Перед передачей изменений

- Проверяем пути к ресурсам на всех страницах.
- Запускаем `npm start` и открываем `http://127.0.0.1:8000`.
- Проверяем главную и внутренние страницы, включая мобильную ширину.
- Убеждаемся, что нет горизонтального скролла, битых изображений и ошибок в консоли.
- Макетные фото, цены, отзывы и данные врачей не выдаём за подтверждённые без согласования.
