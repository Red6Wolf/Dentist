# Стоматология «Апельсин» — сайт

Адаптивный сайт без сборщика и сторонних npm-зависимостей. Страницы написаны
на HTML, CSS и JavaScript. Небольшой сервер на Python отдаёт файлы сайта
и отправляет заявки на обратный звонок через SMTP.

## Запуск на Mac

Откройте Terminal в этой папке и выполните:

```bash
npm start
```

Затем откройте http://127.0.0.1:8000. Остановить сервер можно сочетанием Ctrl+C.

Для запуска нужен Python 3. Можно запустить сервер напрямую:
`python3 server/app.py`.

## Отправка заявок

Без SMTP-настроек сайт открывается, звонок по кнопке работает, а форма
показывает сообщение о временной недоступности. Для отправки заявок задайте
переменные окружения перед запуском:

```bash
export SMTP_HOST="smtp.example.com"
export SMTP_PORT="587"
export SMTP_USER="user@example.com"
export SMTP_PASSWORD="пароль-приложения"
export SMTP_FROM="user@example.com"
export BOOKING_TO="info@stomatologiya-apelsin.ru"
npm start
```

Порт `587` использует STARTTLS, порт `465` — SSL. Пароль не сохраняйте в
репозитории. При размещении сайта настройте эти переменные у хостера и
обеспечьте HTTPS. Обычный статический хостинг не сможет отправлять заявки
через этот обработчик: нужен запуск Python-приложения или другой сервис форм.

## Структура

```text
.
├── index.html                 # главная страница
├── pages/                     # внутренние страницы сайта
├── styles/                    # общие и страничные стили
├── scripts/                   # интерактивность
├── server/                    # обработчик формы и локальный веб-сервер
├── assets/
│   ├── clinic/                # фото клиники и сюжетные изображения
│   ├── doctors/               # портреты врачей
│   ├── illustrations/         # нарисованные элементы оформления
│   └── licenses/              # опубликованные сканы лицензии
├── DESIGN.md                 # визуальные правила
├── PRODUCT.md                # продуктовый контекст
├── CONTRIBUTING.md           # правила читабельного кода и новых файлов
├── VERSIONS.md               # точки сохранения и возврат к ним
├── CONTENT-REVIEW.md          # сведения, которые нужно подтвердить перед публикацией
├── robots.txt                 # правила обхода для поисковых систем
├── sitemap.xml                # карта страниц для поисковых систем
└── README.md                 # запуск и описание проекта
```

- `index.html` — разметка страницы
- `pages/` — отдельные страницы услуг, врачей, клиники и контактов
- `styles/styles.css` — основное оформление и адаптивные состояния
- `styles/pages.css` — общие стили дополнительных страниц
- `styles/home.css` — слайдер направлений, апельсиновый фон и блок карты
- `styles/booking-dialog.css` — оформление окна связи и формы обратного звонка
- `DESIGN.md` — дизайн-контракт и чек-лист перед публикацией
- `PRODUCT.md` — подтверждённый продуктовый контекст для дальнейшей работы
- `CONTRIBUTING.md` — правила форматирования кода и размещения новых файлов
- `VERSIONS.md` — история точек сохранения в GitHub и безопасный способ возврата
- `CONTENT-REVIEW.md` — перечень материалов для проверки перед публикацией
- `scripts/app.js` — появление секций при прокрутке
- `scripts/contact.js` — сохранение выбранного врача при переходе к записи
- `scripts/catalogue.js` — поиск по прайсу и открытие разделов по прямым ссылкам
- `scripts/home.js` — переключение направлений на главной странице
- `scripts/doctors.js` — плавное раскрытие сведений о врачах
- `scripts/scroll.js` — мягкая прокрутка колесом мыши на настольных устройствах
- `scripts/clinic-gallery.js` — увеличение фотографий клиники внутри страницы
- `scripts/booking-dialog.js` — окно связи и отправка заявки на всех страницах
- `server/app.py` — API обратного звонка и раздача статических файлов
- `assets/clinic/` — фотографии интерьера и сюжетные изображения
- `assets/icons/` — SVG-значки для кнопок и ссылок
- `assets/doctors/` — портреты для карточек врачей. Портреты с именами по ID профиля взяты с прежнего сайта клиники.
- `assets/licenses/` — три скана из раздела лицензий прежнего сайта
- `assets/illustrations/` — векторная иллюстрация апельсинового среза

Каталог услуг и полный прайс находятся в `pages/services.html`. Якоря цен имеют формат `p01-01`, а якоря услуг — `service-984`. Ссылки «Смотреть цены» в каталоге фильтруют прайс по этим якорям.

Форма обратного звонка отправляет заявку на `/api/callback`. Без SMTP-настроек
посетитель увидит запасной способ связи — телефон клиники.

Перенесённые цены и портреты сверены с [прежним сайтом клиники](https://stomatologiya-apelsin.ru/). Сканы и реквизиты отражают опубликованный документ. Перед публичным запуском подтвердите актуальность цен, состава команды, фотографий и лицензии у клиники.
