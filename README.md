# Стоматология «Апельсин» — сайт

Адаптивный сайт без сборщика и сторонних npm-зависимостей. Страницы написаны
на HTML, CSS и JavaScript. Небольшой сервер на Python отдаёт файлы сайта
и отправляет заявки на обратный звонок через SMTP.

## Запуск на Mac

Откройте Terminal в этой папке и выполните:

```bash
npm start
```

Затем откройте http://127.0.0.1:8000. Остановить сервер можно сочетанием Ctrl+C.

Для запуска нужен Python 3. Можно запустить сервер напрямую:
`python3 server/app.py`.

## Резервный обработчик заявок

Сейчас кнопки записи открывают набор номера клиники. В проекте оставлен обработчик
формы для будущего подключения. Если форма понадобится, задайте переменные
окружения перед запуском:

```bash
export SMTP_HOST="smtp.example.com"
export SMTP_PORT="587"
export SMTP_USER="user@example.com"
export SMTP_PASSWORD="пароль-приложения"
export SMTP_FROM="user@example.com"
export BOOKING_TO="info@stomatologiya-apelsin.ru"
npm start
```

Порт `587` использует STARTTLS, порт `465` — SSL. Пароль не сохраняйте в
репозитории. При размещении сайта настройте эти переменные у хостера и
обеспечьте HTTPS. Обычный статический хостинг не сможет отправлять заявки
через этот обработчик: нужен запуск Python-приложения или другой сервис форм.

## Структура

```text
.
├── index.html                 # главная страница
├── pages/                     # внутренние страницы сайта
├── styles/                    # общие и страничные стили
├── scripts/                   # интерактивность
├── server/                    # обработчик формы и локальный веб-сервер
├── assets/
│   ├── clinic/                # фото клиники и сюжетные изображения
│   ├── doctors/               # портреты врачей
│   ├── services/              # сгенерированные изображения направлений
│   ├── fonts/                 # Comfortaa для первого экрана, лицензия OFL
│   ├── illustrations/         # нарисованные элементы оформления
│   └── licenses/              # опубликованные сканы лицензии
├── DESIGN.md                 # визуальные правила
├── PRODUCT.md                # продуктовый контекст
├── CONTRIBUTING.md           # правила читабельного кода и новых файлов
├── VERSIONS.md               # точки сохранения и возврат к ним
├── CONTENT-REVIEW.md          # сведения, которые нужно подтвердить перед публикацией
├── robots.txt                 # правила обхода для поисковых систем
├── sitemap.xml                # карта страниц для поисковых систем
└── README.md                 # запуск и описание проекта
```

- `index.html` — разметка страницы
- `pages/` — отдельные страницы услуг, врачей, клиники и контактов
- `styles/styles.css` — основное оформление и адаптивные состояния
- `styles/pages.css` — общие стили дополнительных страниц
- `styles/home.css` — слайдер направлений, вращение апельсина и блок карты
- `styles/home-hero.css` — первый экран со светлым паспарту, тонким апельсиновым контуром и устойчивым переключением аудитории
- `styles/experience-polish.css` — одинаковые CTA, состояния ссылок, компактная мобильная подача и общий контактный блок
- `styles/refinement.css` — общая система отступов, поверхностей, типографики и состояний элементов
- `DESIGN.md` — дизайн-контракт и чек-лист перед публикацией
- `PRODUCT.md` — подтверждённый продуктовый контекст для дальнейшей работы
- `CONTRIBUTING.md` — правила форматирования кода и размещения новых файлов
- `VERSIONS.md` — история точек сохранения в GitHub и безопасный способ возврата
- `CONTENT-REVIEW.md` — перечень материалов для проверки перед публикацией
- `scripts/home.js` — смена слайдов и запуск вращения апельсина при прокрутке
- `scripts/navigation.js` — меню компьютера и телефона, плавное открытие с поддержкой клавиатуры
- `scripts/interactions.js` — обратная связь текстовых ссылок и прерываемое раскрытие нативных details; уступает существующим обработчикам компонентов
- `scripts/contact.js` — сохранение выбранного врача при переходе к записи
- `scripts/catalogue.js` — поиск по прайсу и открытие разделов по прямым ссылкам
- `scripts/prices.json` и `scripts/render_prices.py` — данные цен и обновление статических таблиц
- `scripts/doctors.js` — плавное раскрытие сведений о врачах
- `scripts/clinic-gallery.js` — увеличение фотографий клиники внутри страницы
- `server/app.py` — API обратного звонка и раздача статических файлов
- `assets/clinic/` — фотографии интерьера и сюжетные изображения
- `assets/services/` — сгенерированные иллюстрации направлений стоматологии
- `assets/icons/` — SVG-значки для кнопок и ссылок
- `assets/doctors/` — портреты для карточек врачей. Портреты с именами по ID профиля взяты с прежнего сайта клиники.
- `assets/licenses/` — три скана из раздела лицензий прежнего сайта
- `assets/illustrations/` — векторная иллюстрация апельсинового среза

Каталог находится в `pages/services.html`, поиск по ценам и полный прайс — в `pages/prices.html`. Якоря цен имеют формат `p01-01`, якоря услуг — `service-984`. Название процедуры в каталоге открывает страницу услуги; её цены берутся из единого прайса. Старые ссылки на прайс в каталоге автоматически ведут на новую страницу.

Кнопки звонка открывают набор номера клиники. На 13 подробных страницах услуг внизу размещена форма: ФИО, телефон и отдельное обязательное согласие. `/api/callback` проверяет согласие на сервере и отправляет письмо через SMTP. Без настроек доставки форма показывает ошибку и сохраняет введённые данные; успех показывается только после приёма письма SMTP-сервером.

Перенесённые цены и портреты сверены с [прежним сайтом клиники](https://stomatologiya-apelsin.ru/). Сканы и реквизиты отражают опубликованный документ. Перед публичным запуском подтвердите актуальность цен, состава команды, фотографий и лицензии у клиники.

### Обновление цен

Измените нужные суммы в `scripts/prices.json`, затем выполните
`python3 scripts/render_prices.py`. Скрипт обновит таблицы на главной,
в общем прайсе и на страницах направлений, а также сверит привязки услуг к ценам. Команда
`python3 scripts/render_prices.py --check` проверяет, совпадают ли таблицы с данными.


### Информация для пациента

- `pages/first-visit.html` — вопросы для первого посещения, тревога и визит с ребёнком.
- `pages/implantation.html`, `pages/veneers.html`, `pages/orthodontics.html` — подготовка к консультации и отдельные цены направления.
- `styles/care.css` — общие компоненты этих разделов.
- Примеры стоимости и таблицы новых страниц обновляет `scripts/render_prices.py` из `scripts/prices.json`.
- Нажатия на телефон, переходы к врачу/первому визиту и пустой результат поиска отправляются в `window.dataLayer`. Подключение аналитической системы выполняется после выбора провайдера и счётчика.
- Слайдер автоматически меняет кадры, останавливается при наведении мыши и фокусе клавиатуры. Системная настройка уменьшения движения отключает автоматическую смену.

### Навигатор услуг

На `pages/services.html` показаны десять карточек направлений: три процедуры видны сразу, остальные раскрываются внутри карточки. Вложенной прокрутки нет. Поиск работает по каталогу и отдельным позициям прайса; ссылки на подробные страницы лечения и цены сохранены.
`scripts/services.js` управляет навигатором, `styles/services.css` задаёт его компоновку.
Поисковый индекс процедур генерируется в инертный HTML-шаблон из `scripts/prices.json` командой `python3 scripts/render_prices.py`.
Поиск и область поиска сохраняются в URL. Без JavaScript доступны исходные раскрывающиеся направления. Крупные иллюстрации направлений хранятся в отдельных `assets/services/direction-*.webp`; соответствия заданы в `scripts/service_images.json` и включаются в генерируемый `service-routes.js`. Это сгенерированные предметные изображения, а не клинические результаты.

## Единый прайс

`pages/prices.html` показывает все цены без промежуточных страниц. Поиск (`q`), направление (`direction`) и подборка услуги (`service`) сохраняются в адресе; якорь `#p01-01` открывает конкретную строку. `styles/prices.css` задаёт компоновку фильтров. Старые `price-*.html` генерируются как страницы перехода через `scripts/price-redirect.js`. Без JavaScript доступна ссылка перехода, а весь основной прайс — через обычные раскрывающиеся разделы.

Результат сверки со старым сайтом описан в `PRICE-MIGRATION.md`. Для повторной сверки сохранённого HTML используется `scripts/check_price_migration.py`.

## Страницы услуг и путь к консультации

Процедуры из каталога открывают содержательные страницы. `scripts/service_pages.json` задаёт тексты и выбранные позиции прайса десяти новых страниц. Для близких процедур сохраняется контекст `?service=ID`, а общая страница объясняет направление. Имплантация, виниры и ортодонтия используют существующие страницы.

`python3 scripts/render_prices.py` обновляет все представления цен и вызывает `scripts/render_service_pages.py`. Команда с `--check` проверяет также страницы услуг и `scripts/service-routes.js`. Последний файл генерируется из 79 исходных названий и 164 цен; вручную его не редактируют.

`scripts/consultation.js` сохраняет выбранную услугу и связанные цены, обновляет хлебные крошки и подсвечивает текущий раздел страницы. Памятка с чекбоксами удалена. Подготовка к первому визиту показана прямо на странице услуги. Основное действие — звонок для консультации через `tel:`.

## Семейный сценарий и общие части страниц

- Первый экран переключается между `?audience=adult` и `?audience=child`; назад/вперёд восстанавливает выбранный сценарий. Общий каталог остаётся доступен.
- `scripts/render_shared.py` содержит общую инструкцию первого визита, хлебные крошки и правовой подвал. Он вызывается генератором услуг.
- `styles/patient-experience.css` отделяет стоимость, этапы и подготовку цветом, увеличивает изображения и задаёт закреплённое меню разделов.
- `scripts/navigation.js` раскрывает направления и информацию о клинике на ПК; на телефоне меню находится справа в шапке.
- `pages/privacy-policy.html` воспроизводит текст исходной политики клиники. Перед публикацией его нужно сверить с фактически подключёнными формами и аналитикой.
- Новые `assets/clinic/hero-adult-v2.webp` и `hero-child-v2.webp` — сгенерированные сюжетные иллюстрации, не фотографии пациентов. Их prompts и происхождение сохранены в соседних JSON.


## Сценарии главной и первый визит

`scripts/home-audience.js` переключает услуги, цены, подсказки родителям и подборку существующих отзывов вслед за выбором «Взрослым / Детям». Адрес и часы общие. Детские цены генерируются из `scripts/prices.json` командой `python3 scripts/render_prices.py`; ручного второго прайса нет. История браузера восстанавливает выбранный режим.

Общий блок первого визита и форма создаются в `scripts/render_shared.py`. После изменений: `python3 scripts/render_service_pages.py`, затем `python3 scripts/render_prices.py --check` и `python3 scripts/render_service_pages.py --check`. Отдельный документ согласия: `pages/personal-data-consent.html`. Проверки API без реальных писем: `python3 -m unittest discover -s server -v`.


## Каталог и общий интерфейс после обновления

Каталог разделён на «Взрослым / Детям» с параметром `audience` в URL. Детский поиск использует подтверждённые связи позиций прайса; дополнительные процедуры профилактики ведут на конкретные строки единого прайса. Прямые ссылки на скрытые основные процедуры прокручивают к их постоянно видимому дублю; первые три пункта не исчезают при раскрытии остальных.

Первый экран сохраняет выбранную композицию с фотографией слева и абрикосовой текстовой панелью справа. Широкое скругление со стороны фотографии и тонкий полный контур отсылают к апельсиновой дольке; снаружи сохранено светлое паспарту. На телефоне скругление компактнее, а текст и действия предшествуют фотографии. Ссылка «Узнать стоимость» открывает общий прайс для взрослых и детскую подборку для родителей. Comfortaa 500 сохранён локально в `assets/fonts/`, лицензия — `Comfortaa-OFL.txt`; Python-сервер разрешает публичную выдачу `.woff2`. При переходе между аудиториями изображения имеют один размер, а высота описания измеряется по обоим текстам.

`contact_callout()` в `scripts/render_shared.py` задаёт единый контактный блок для главной и контактов. Отправка формы на подробных страницах по-прежнему требует SMTP. Иллюстрации эстетики и имплантации обновлены до v4; остальные направления и сюжетные сцены сохраняют выбранные ранее версии. Исходные файлы сохранены. Точные промпты и происхождение находятся в соседних `.webp.json`.

На главной контактный блок снова явно предлагает запись на консультацию и отличается тёплой персиковой поверхностью. Он меняет заголовок и пояснение в детском сценарии. Страница врачей использует компактное вступление и навигацию по специализациям; первый портрет виден без длинного вводного экрана. Подпись логотипа выровнена по базовой линии названия.
