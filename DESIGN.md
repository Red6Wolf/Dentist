# Дизайн-контракт «Апельсина»

Этот файл задаёт визуальные правила для главной и дополнительных страниц. Новую секцию сначала сверяем с ним, потом добавляем в HTML и CSS.

## Характер

Семейная клиника рядом с домом: спокойно, тепло, точно и без рекламного шума. Визуальный ориентир — редакционный медицинский сайт с крупной фотографией и большим количеством воздуха.

## Цветовые роли

| Роль | Токен | Назначение |
| --- | --- | --- |
| Основной фон | `--cream` | страницы, карточки, поля |
| Второй фон | `--sand` | отзывы, контакты, мягкое выделение |
| Текст | `--ink` | заголовки и основной текст |
| Вторичный текст | `--muted` | подписи, пояснения, метаданные |
| Апельсиновый акцент | `--orange` | кнопки, активные состояния, маркеры |
| Тёмный акцент | `--orange-deep` | ссылки и мелкие акцентные подписи |
| Разделитель | `--line` | границы и линии таблиц |

Правило: акцент занимает небольшую часть экрана. Не использовать оранжевый как фон больших секций и не добавлять новые оттенки без роли.

## Типографика и сетка

- Manrope используется для текста и заголовков, DM Mono — для коротких служебных меток.
- У секций один главный заголовок и один поясняющий абзац.
- Карточки используют одинаковые радиусы и одинаковые внутренние отступы.
- Длинные абзацы ограничиваются шириной, чтобы строка не становилась тяжёлой для чтения.
- На мобильном экране сначала сохраняем читаемость, потом плотность контента.

## Анимация

- Появление секции: небольшое смещение вверх и прозрачность.
- Наведение: только лёгкий сдвиг, изменение границы или масштаба фотографии.
- Нет бесконечных эффектов, резких масштабирований и движения ради движения.
- `prefers-reduced-motion` всегда отключает заметные переходы.

## Гейт перед публикацией

- Все страницы открываются напрямую и связаны общей навигацией.
- Нет горизонтального переполнения на мобильном экране.
- У каждого интерактивного элемента есть видимый `:focus-visible`.
- Основной текст и кнопки сохраняют контраст WCAG AA.
- Фото врачей, цены и отзывы подтверждены клиникой.
- Временные материалы явно помечены и не воспринимаются как фактические данные.
